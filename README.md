# dst-templates

Exercise templates for the course **Designing, Specifying, and Testing Distributed
Systems** (DST), written in [Zig](https://ziglang.org/).

## Templates

| #    | Topic         | Task                                                                        | Entry point                                                |
| ---- | ------------- | --------------------------------------------------------------------------- | ---------------------------------------------------------- |
| `01` | Zig intro     | Implement a hash table with open addressing                                 | [`01/src/hashtable.zig`](01/src/hashtable.zig)             |
| `02` | State machine | Implement a key-value state machine: hash table, wire format, apply         | [`02/src/kv.zig`](02/src/kv.zig)                           |
| `03` | Message bus   | Implement a message pool and its buffers                                    | [`03/src/vsr/message_bus.zig`](03/src/message_pool.zig)    |
